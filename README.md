# HRTX / beam — เฟส 2

เว็บไซต์ภาษาไทยสำหรับวิเคราะห์และออกแบบคานภายใต้แบรนด์ HRTX

เว็บไซต์: https://hrtx23.github.io/hrtx-beam/

## การปรับปรุง
- แก้การแจ้งคานไม่เสถียรเมื่อแรงอยู่ใกล้กันมาก โดยแก้สมการสมดุลและเงื่อนไขรองรับโดยตรงในพิกัด normalized
- คงตำแหน่งแรงที่กรอกโดยไม่ปัดพิกัดก่อนคำนวณ
- หาจุดโมเมนต์สูงสุดด้วยรากพหุนามในช่วง normalized
- ตรวจค่าคลาดเคลื่อนของสมการและสมดุลก่อนยอมรับผล ไม่ผ่านหากเกิน 1e-8
- แสดงเกณฑ์การโก่งตัวตามที่เลือกจริง (L/n หรือค่าระบุเอง)
- ป้องกันหน้าตัดประกอบที่ทับพื้นที่กัน และตรวจข้อมูล E/I/เกณฑ์ก่อนออกแบบ
- เพิ่มส่งออก JSON และ CSV พร้อมหน่วย ค่าซ้าย/ขวาที่จุดกระโดด และจุดวิกฤต

## เริ่มใช้งาน
เปิด index.html ในเบราว์เซอร์ ไม่ต้องติดตั้งแพ็กเกจ

## ทดสอบ
ติดตั้ง Node.js แล้วรันจากโฟลเดอร์โปรเจกต์:

    node tests/verify.cjs

ทดสอบสมการสำเร็จรูป คานช่วงเดียว คานยื่น ยึดแน่นสองปลาย ยึดแน่นร่วม roller คานต่อเนื่อง แรงสามเหลี่ยม แรงกระจายบางช่วง คู่ควบ การกลับทิศแรง SI/US แรงใกล้กัน เงื่อนไขรองรับ ความต่อเนื่อง ข้อมูลผิด และคุณสมบัติหน้าตัด

## ขอบเขต
Euler–Bernoulli, E/I คงที่, วัสดุยืดหยุ่นเชิงเส้น, การโก่งตัวขนาดเล็ก การส่งออก JSON เป็นรายงานผล ไม่ใช่ไฟล์นำเข้ากลับ ระบบยังไม่ตรวจ buckling, torsion, connections, load combinations หรือแรงรวมตามมาตรฐาน หน้าตัดเหล็กฉากใช้สูตรประมาณเดิม ไม่ใช่การแก้ unsymmetric bending; หน้าตัดหลายชิ้นสมมติทำงานร่วมกัน ข้อมูลตารางหน้าตัดยังมาจากต้นฉบับและไม่ได้รับรองทีละแถว

ค่าคลาดเคลื่อนที่แสดงเป็นความคลาดเคลื่อนเชิงตัวเลขของสมการ ไม่ใช่ค่าความถูกต้องของแบบจำลองจริง
