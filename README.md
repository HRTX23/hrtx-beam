# HRTX / beam

เว็บไซต์ภาษาไทยสำหรับวิเคราะห์และออกแบบคาน ภายใต้แบรนด์ HRTX

## เริ่มใช้งาน
เปิด `index.html` ในเบราว์เซอร์ หรือเผยแพร่เป็นเว็บไซต์ static

## ความสามารถ
- ตั้งค่ารูปแบบคานและแรงกระทำ
- แสดงผลวิเคราะห์และแผนภาพแรง
- เลือกหน้าตัดและตรวจสอบผลออกแบบ
- สลับหน่วย SI / US และธีมสว่าง / มืด
- รองรับหน้าจอมือถือ

## งานออกแบบ
ใช้ชื่อบริษัท HRTX และคงสัญลักษณ์ b. สีม่วงจากต้นฉบับ พร้อมลายเส้นที่ได้แรงบันดาลใจจากแบบโครงสร้าง

## โครงสร้างไฟล์
- `index.html` — หน้าเว็บ สไตล์ และฟังก์ชันคำนวณ
- `.nojekyll` — ให้ GitHub Pages เสิร์ฟไฟล์ static โดยตรง

ฟอนต์โหลดจาก Google Fonts; ฟังก์ชันคำนวณทำงานในเบราว์เซอร์ โค้ดคำนวณคงตามไฟล์ต้นฉบับ การปรับครั้งนี้เป็นการปรับแบรนด์และหน้าตา
