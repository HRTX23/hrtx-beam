# HRTX / beam

**ระบบวิเคราะห์และออกแบบหน้าตัดคานผ่านเว็บเบราว์เซอร์**

HRTX / beam เป็นเครื่องมือภาษาไทยภายใต้บริษัท HRTX สำหรับวิเคราะห์พฤติกรรมของคานและประเมินหน้าตัดตามข้อมูลแรง วัสดุ และเกณฑ์ที่ผู้ใช้งานกำหนด ระบบแสดงผลคำนวณ แผนภาพ และขั้นตอนประกอบการวิเคราะห์ เพื่อให้สามารถตรวจสอบผลลัพธ์ได้อย่างเป็นระบบ

[เข้าใช้งานเว็บไซต์](https://hrtx23.github.io/hrtx-beam/) · [ตรวจสอบผลการทดสอบ](https://github.com/HRTX23/hrtx-beam/actions)

## วัตถุประสงค์

สนับสนุนการศึกษา การตรวจสอบโจทย์ และการประเมินคานเบื้องต้น โดยรวบรวมการกำหนดแบบจำลอง การวิเคราะห์แรงภายใน และการตรวจสอบหน้าตัดไว้ในระบบเดียว

## ความสามารถของระบบ

| หมวด | รายละเอียด |
| --- | --- |
| แบบจำลองคาน | รองรับคานช่วงเดียว คานมีส่วนยื่น คานยื่น คานยึดแน่นสองปลาย คานยึดแน่นร่วมกับจุดรองรับแบบลูกกลิ้ง และคานต่อเนื่อง |
| แรงกระทำ | กำหนดแรงจุด แรงกระจายคงที่หรือแปรผันเชิงเส้น และโมเมนต์คู่ควบ |
| ผลการวิเคราะห์ | คำนวณแรงปฏิกิริยา แรงเฉือน โมเมนต์ดัด และตำแหน่งค่าวิกฤต พร้อมแผนภาพประกอบ |
| การโก่งตัว | คำนวณการโก่งตัวและมุมหมุนจากค่า E และ I พร้อมตรวจเกณฑ์ L/n หรือค่าจำกัดที่ระบุ |
| การตรวจสอบหน้าตัด | ประเมินความเค้นดัดและความเค้นเฉือนตามเกณฑ์ที่เลือก ใช้หน้าตัดจากตารางหรือกำหนดมิติเอง |
| เครื่องมือเพิ่มเติม | คำนวณความเค้น ณ จุด ประเมินขนาดแรงที่รับได้ และหาความกว้างขั้นต่ำของหน้าตัดสี่เหลี่ยมภายใต้เงื่อนไขที่รองรับ |
| การตรวจสอบเชิงตัวเลข | ตรวจสมดุลแรง สมดุลโมเมนต์ และค่าคลาดเคลื่อนของสมการก่อนยอมรับผลวิเคราะห์ |
| การส่งออก | ส่งออกรายงาน JSON และข้อมูลผลวิเคราะห์ CSV พร้อมหน่วยและค่าที่ตำแหน่งสำคัญ |
| การใช้งาน | รองรับระบบหน่วย SI และ US ธีมสว่างและมืด และการจัดวางสำหรับหน้าจอขนาดต่าง ๆ |

## วิธีใช้งาน

1. เปิด [เว็บไซต์ HRTX / beam](https://hrtx23.github.io/hrtx-beam/)
2. เลือกรูปแบบคาน ระบุความยาว และกำหนดจุดรองรับ
3. เพิ่มแรงกระทำ พร้อมระบุตำแหน่ง ขนาด และทิศทาง
4. เลือกระบบหน่วย และระบุค่า E, I และเกณฑ์การโก่งตัวเมื่อต้องการตรวจสอบ
5. เลือก **วิเคราะห์คาน** เพื่อดูผลคำนวณ แผนภาพ และขั้นตอนการวิเคราะห์
6. หากต้องการตรวจหน้าตัด ให้กำหนดข้อมูลวัสดุ เกณฑ์ความเค้น และหน้าตัดในหน้า **ออกแบบหน้าตัด**
7. ตรวจสอบสถานะของแต่ละรายการ และส่งออกรายงานตามต้องการ

การส่งออก JSON ใช้สำหรับบันทึกแบบจำลองและผลวิเคราะห์ ปัจจุบันยังไม่รองรับการนำเข้ารายงานกลับเข้าสู่ระบบ

## หลักการคำนวณและขอบเขตการใช้งาน

ระบบใช้แบบจำลองคาน Euler–Bernoulli ภายใต้สมมติฐานว่าวัสดุมีพฤติกรรมยืดหยุ่นเชิงเส้น การโก่งตัวมีขนาดเล็ก และค่าโมดูลัสยืดหยุ่น E กับโมเมนต์ความเฉื่อย I คงที่ตลอดคาน โดยไม่รวมการโก่งตัวจากแรงเฉือน

ขอบเขตที่ต้องพิจารณาประกอบการใช้งาน:

- ผลการตรวจหน้าตัดครอบคลุมเฉพาะรายการและเกณฑ์ที่เลือก รายการที่ยังไม่ตรวจจะแสดงสถานะแยกต่างหาก
- ระบบยังไม่ตรวจสอบการโก่งเดาะ การบิด รอยต่อ หรือชุดแรงและเกณฑ์ปฏิสัมพันธ์ตามมาตรฐานการออกแบบ
- การตรวจเหล็กฉากใช้สูตรประมาณ และยังไม่ครอบคลุมการดัดแบบไม่สมมาตรอย่างสมบูรณ์
- หน้าตัดหลายชิ้นสมมติให้ทำงานร่วมกัน โดยยังไม่ตรวจรายละเอียดการยึดต่อ
- ข้อมูลตารางหน้าตัดต้องตรวจสอบกับเอกสารอ้างอิงที่ใช้ในงานแต่ละโครงการ และยังไม่ได้รับรองความถูกต้องครบทุกแถว
- ค่าคลาดเคลื่อนที่แสดงเป็นค่าคลาดเคลื่อนเชิงตัวเลขของการแก้สมการ ไม่ใช่ค่าประเมินความคลาดเคลื่อนของโครงสร้างจริง

ผลลัพธ์มีวัตถุประสงค์เพื่อสนับสนุนการวิเคราะห์และการประเมินเบื้องต้น การนำไปใช้ในงานออกแบบจริงต้องตรวจสอบความเหมาะสมของแบบจำลอง ข้อมูล และมาตรฐานที่เกี่ยวข้องโดยผู้รับผิดชอบงานออกแบบ

## การใช้งานจากไฟล์โครงการ

ดาวน์โหลดไฟล์โครงการและเปิด `index.html` ในเว็บเบราว์เซอร์ โดยไม่ต้องติดตั้งแพ็กเกจสำหรับการใช้งานทั่วไป การคำนวณทำงานในเบราว์เซอร์ ส่วนฟอนต์โหลดจาก Google Fonts

เว็บไซต์เผยแพร่ผ่าน GitHub Pages โดยใช้ไฟล์จากสาขา `main`

## โครงสร้างโครงการ

```text
hrtx-beam/
├── index.html                 # หน้าจอใช้งานและระบบคำนวณ
├── README.md                  # เอกสารโครงการ
├── .nojekyll                  # การตั้งค่าสำหรับเว็บไซต์ static บน GitHub Pages
├── tests/
│   └── verify.cjs             # ชุดทดสอบการคำนวณ
└── .github/
    └── workflows/
        └── verify.yml         # การทดสอบอัตโนมัติบน GitHub Actions
```

## การทดสอบและตรวจสอบผล

โครงการมีชุดทดสอบการคำนวณ **1,001 ข้อ** ครอบคลุมกรณีคานและแรงมาตรฐาน การแปลงหน่วย SI/US เงื่อนไขจุดรองรับ ความต่อเนื่องของการโก่งตัว แรงที่อยู่ใกล้กัน ขนาดแรงที่แตกต่างกัน คุณสมบัติหน้าตัด และเครื่องมือคำนวณเพิ่มเติม

สำหรับผู้พัฒนา ให้ติดตั้ง Node.js และรันคำสั่งต่อไปนี้จากโฟลเดอร์โครงการ:

```sh
node tests/verify.cjs
```

GitHub Actions จะเรียกใช้ชุดทดสอบเมื่อมีการส่งโค้ดเข้าสู่สาขา `main` หรือเปิด Pull Request ผลการทดสอบยืนยันเฉพาะกรณีที่อยู่ในชุดทดสอบ และไม่ใช่การรับรองแบบจำลองสำหรับงานวิศวกรรมทุกประเภท
